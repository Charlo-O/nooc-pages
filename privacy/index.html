隐私政策

本政策说明 Nooc 如何处理你主动提供的文本、设置和导出内容，以及外部 AI 服务请求的流转方式。

生效日期：2026 年 4 月 4 日。最近更新日期：2026 年 8 月 28 日。

1. 我们是谁

本应用为 Nooc（下称“本应用”）的 iPhone 应用版本，用于用户原创文稿分析、结构化整理、角色对话与续写辅助。

运营名称：Nooc

官网：https://nooc.top

联系邮箱：support@nooc.top

2. 我们处理哪些数据

本应用不提供开发者托管账号系统，也不要求用户注册登录。

本应用可能处理以下几类信息：

  • 用户主动输入、粘贴或导入的文本内容。
  • 用户主动填写的 AI 接口配置，例如 API Base URL、API Key、模型名称。
  • 用户在应用内生成的分析结果、聊天记录、剧本草稿、历史记录。
  • 用户主动导出或分享的文件内容。

3. 数据如何被使用

上述数据仅用于以下目的：

  • 在设备本地保存用户设置、历史记录、聊天记录、草稿和待处理文本。
  • 根据用户指令，对文本进行分析、整理、聊天或续写。
  • 在用户主动导出或分享时，生成对应文件并交给系统处理。

4. 关于第三方 AI 接口

iPhone 版本默认使用安装包内置的端侧模型；在端侧模式下，AI 请求在当前设备完成，不会发送给第三方 AI 服务。

本应用不提供开发者自有 AI 服务端。仅当用户主动配置并选择云端 API 模式时，AI 分析、AI 聊天或 AI 续写请求才会从用户设备直接发送到用户自行填写的 OpenAI 兼容接口或其他兼容服务。

这意味着：用户输入的文本、用户填写的 API Key、模型名称以及相关请求数据，可能会被发送到用户指定的第三方服务提供方。该第三方服务如何保存、使用或保留数据，取决于该服务提供方自身的政策，而不由本应用控制。

用户在填写并使用外部接口前，应自行确认对应服务的隐私政策、数据保留规则与安全机制。

5. 本地存储

为保证使用连续性，本应用会将以下内容保存在用户当前设备或当前浏览器的本地存储中：

  • API Base URL、模型名称等非敏感设置；API Key 单独保存在系统 Keychain。
  • 分析历史与结果文件
  • 角色聊天记录
  • 待处理文本和剧本草稿

这些内容默认保存在用户当前设备中，而不是上传到开发者自有服务器。

6. 权限与系统能力

当前版本可能使用以下系统能力：

  • 文件选择：用于导入文本文件。
  • 文件读写：用于在本地保存分析结果和导出文件。
  • 系统分享：用于将用户主动选择的结果文件分享给其他应用。

当前版本不主动请求以下敏感权限：

  • 相机
  • 麦克风
  • 定位
  • 通讯录
  • 跟踪（Tracking）

7. 数据共享与披露

除以下情形外，我们不会主动将用户数据共享给开发者自有后台或出售给第三方：

  • 用户主动配置第三方 AI 接口并发起 AI 请求时，请求会直接发送到用户指定的服务。
  • 用户主动使用系统分享功能时，所选文件会按用户操作分享给目标应用或服务。
  • 如法律法规、司法机关或监管部门要求披露的情形。

8. 数据删除与用户控制

用户可通过以下方式控制数据：

  • 在应用内清空聊天记录、历史记录或重新覆盖 API 设置。
  • 删除已导出的本地文件。
  • 卸载应用，以移除应用沙盒中的本地存储数据。

9. 未成年人

本应用不以未成年人为主要目标用户。若你是未成年人的监护人，并认为未成年人未经授权向本应用输入了个人信息，请通过下方联系方式联系我们，我们会在合理范围内协助处理。

10. 政策更新

如本政策发生变更，我们会在发布新版本或更新网站页面时同步更新内容。更新后的版本以页面展示的最新日期为准。

11. 联系我们

如你对本隐私政策有任何疑问，或需要就数据访问、删除、纠错等问题联系我们，请发送邮件至：

support@nooc.top

你也可以访问支持与联系页面获取支持信息。
