常见说明

1. 本应用不提供开发者托管账号系统，也不要求用户注册登录。

2. AI 分析、聊天和续写默认使用安装包内置的端侧模型，在设备本地完成，无需账号、网络连接或 API Key。

3. 如需使用云端模式，可以在“设置”页自行填写 HTTPS OpenAI 兼容接口地址、API Key 和模型名称。启用后，文本会直接从设备发送到你配置的 AI 服务，不经过开发者自有服务端中转；API Key 保存在系统 Keychain。

4. 若云端模式返回错误，请优先检查 Base URL、API Key、模型名称以及目标服务可用性。

建议反馈格式

提交问题时，建议同时提供以下信息，以便尽快排查：

  • 设备型号与 iOS 版本
  • 应用版本号
  • 问题发生页面与操作步骤
  • 错误提示截图或文字
  • 使用的是端侧模型还是云端接口
